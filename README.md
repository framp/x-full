# x-full

A customizable interactive progress bar that fills up with clicks. Features include:

- Configurable number of clicks to fill the progress bar
- Customizable bar length and orientation
- Adjustable end caps (one or two semicircles on each end)
- Gradient colors that transition from purple to pink to red
- Confetti celebration animation when the bar is filled
- Customizable success message

Perfect for interactive elements, gamification, or any UI that needs a satisfying progress indicator.
